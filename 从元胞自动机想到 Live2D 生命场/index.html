从元胞自动机想到 Live2D 生命场

发表于 2026-10-09
  • Aki's Memory
首页 AG99

最近在想 Live2D 表情时，冒出来一个很有意思的灵感：

表情不一定只能被 “选择” 出来。

它也许可以从一个持续演化的场里自然长出来。

这个想法最早让我联想到的是元胞自动机。

元胞自动机很迷人的一点在于：每个格子只遵守非常简单的局部规则，但整个系统跑起来之后，会出现远比规则本身复杂的动态。

比如康威生命游戏。

单个格子只有 “生” 和 “死” 两种状态。

每一步也只是根据周围邻居数量决定下一帧状态。

但它会涌现出：

  • 稳定结构
  • 周期振荡
  • 移动图案
  • 扩散趋势
  • 看起来像活动的结构

规则很小，表现却很丰富。

这给我的启发是：

复杂的表情表现，也许不一定来自更复杂的情绪标签，而可以来自简单状态规则的持续演化。

# 从 “表情标签” 到 “状态场”

传统 Live2D 表情更像一个选择题：

这当然有效。

但它的问题是，表情很容易变成离散标签。

角色像是在切换状态，而不是在持续变化。

元胞自动机给我的另一个启发是：

状态可以不是一个标签，而是一片场。

也就是说，不是问 “现在是什么情绪”，而是观察一片内部状态场：

  • 哪些区域被激发
  • 哪些区域被抑制
  • 哪些区域正在恢复
  • 哪些地方留下了残留
  • 哪些波形正在扩散或消失

表情不再是一个按钮。

表情变成对这片场的读取。

# 生命场的想象

我现在想象的 Live2D 生命场，不是严格复刻传统元胞自动机。

它更像是受几类系统启发：

  • 元胞自动机：局部规则产生全局动态
  • 康威生命游戏：简单规则涌现复杂结构
  • 反应扩散系统：局部激活和抑制形成图案
  • 激发介质：刺激、传播、不应期、恢复
  • 连续动力系统：状态不是跳变，而是缓慢演化

可以先想象一个小网格。

每个格子不只是生或死，而是有几种连续状态：

一个输入进入系统后，不直接变成 “开心” 或 “害羞”。

它只是让某些区域被激发。

然后这片场自己开始变化：

  • 激发向周围传播
  • 压力抑制过强激发
  • 能量被消耗
  • 稳定性让系统慢慢回落
  • 残留记录曾经被激发过的位置

这样，一个表情就不再只是瞬间触发的结果。

它会有来处，有过程，也有消退。

# 残留很重要

我特别在意 residue 这个概念。

因为它让系统不是每次都从零开始。

一次输入过去之后，即使表面上恢复平静，场里仍然可以留下淡淡的痕迹。

下一次类似刺激进来时，旧痕迹可能更容易被重新激发。

这就让角色有了一点 “被影响过” 的感觉。

不是严格意义上的记忆，但像一种内部地形。

同一句话，在不同 residue 分布下，可能激起不同波形。

这比单纯根据文本选择表情更有意思。

# 表情是读出，不是命令

如果这片生命场跑起来，Live2D 可以不直接听命令。

它可以读取场的状态。

比如：

  • 激发整体上升，动作幅度可以变大。
  • pressure 聚集，眼神和身体可以收缩。
  • energy 下降，表情可以变弱。
  • residue 被重新激发，反应可以带一点延续感。
  • 场比较稳定，角色可以表现得平和。
  • 场出现局部冲突，角色可以显得犹豫或害羞。

这样，“害羞” 不是一个被选中的标签。

它可能是一种场形态：

也就是说，表情是从场里读出来的。

不是先有情绪标签，再播放动作。

而是先有内部动态，再出现可见表情。

# 我想验证的灵感

这个想法现在还只是灵感。

真正想验证的是：

  • 简单局部规则能不能产生有生命感的表情动态。
  • 激发、抑制、恢复、残留这些机制，能不能让角色表现更连续。
  • 表情能不能从场状态读出，而不是由 AI 直接选择。
  • 同样的输入，在不同场状态下，能不能产生不同但可解释的反应。
  • Live2D 的眼神、头部、身体、呼吸，能不能来自同一个内部场。

如果这个方向成立，Live2D 角色就不只是 “更会换表情”。

它会更像一个持续运行的小生态：

会被扰动。

会传播。

会抑制。

会恢复。

也会留下痕迹。

一句话总结：

这个灵感来自元胞自动机和生命场：我想验证 Live2D 表情能不能不是被选择出来，而是从一片持续演化的内部状态场里自然长出来。
