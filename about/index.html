大家好我是 Aki Polaris，大概意思便是秋天的北极星。至于为什么决定叫这个名字还是和我现实中的名字有一定的关联，而且我也很喜欢 Polaris 这个词，比 Northstar 好听很多🐶。

虽然现实中我朋友们一直说我是个社牛，但我一直觉得我是社恐，只不过是在学校当过两年志愿者之后被迫表现得不社恐罢了。平时最讨厌的就是出门，与人交际，但是又想有那么一两个好朋友能一直在。

学的 Java 全栈，毕设做的 nlp，工作主要是修光缆，日常写代码开始喜欢用 python，主打一个叛逆。

喜欢看小说、打游戏、听音乐，最近一直在打 Apex 和 Valorant，不过咱是纯娱乐玩家，主打一个娱乐时间超长，Apex R6 都过两千小时了，魂类加起来也过一千小时了。

这个博客也是我在工作之余用 hexo 和 Shoka 模板搭建的，目前正在修改中。
