NeuroBrain：从连续状态到人工心理系统的一次尝试

发表于 2026-10-09
  • Aki's Memory
首页 AG99

最近在优化 AG99live 的 LLM 驱动机制时，我逐渐意识到一个问题。

我们已经能够通过大型语言模型理解对话内容，并根据语义生成相应的表情与动作。对于一般的交互场景，这种方式已经能够取得不错的效果。

但当我试图进一步提高角色表现的自然程度时，发现问题似乎并不完全在于 LLM 的理解能力，也不在于它能否生成准确的表情参数。

真正让我在意的是：角色的状态应该是动态的、连续的，而不是由一连串相互独立的指令构成。

一次动作或刺激产生的影响，不应该随着指令结束而突然消失。

一次惊讶可能会迅速出现，又逐渐减弱；一次不愉快的互动可能持续影响角色接下来的表现；连续发生的事件，也不应该被当成完全独立的输入分别处理。

这就涉及几个问题：

  • 一次输入产生的影响，应该如何随时间变化？
  • 多次输入之间，应该如何相互作用？
  • 系统如何保留此前的状态，并让它影响后续反应？
  • 在没有新输入时，内部状态又应该如何演化？

最初，我尝试从动作插值、衰减函数和状态管理的角度考虑这些问题。

这些方法当然能够解决部分需求，比如让某个参数逐渐恢复，或者让两个动作之间的过渡更加平滑。

但继续深入之后，我发现这可能不是简单增加几个函数就能解决的问题。

因为我希望实现的，不只是某个参数从 1 平滑地回到 0，而是让整个系统拥有自己的状态，并按照一定的规律持续演化。

更进一步，如果我们已经构建了这样一套内部状态系统，那么它似乎也不必只服务于 Live2D。

在 AI 角色扮演、对话生成乃至行为决策中，同样存在状态连续性和历史依赖的问题。

于是，我开始考虑一个更独立的方向：

能否构建一个可训练的动态系统，让角色的心理状态和行为倾向从内部演化过程中产生？

这就是我准备尝试的 NeuroBrain。

# 1. 从离散指令到连续状态

目前很多 AI 角色的交互方式，本质上仍然属于事件驱动的表现生成。

用户输入一段文本，LLM 理解内容，再输出相应的语言、表情或动作指令。

这种方式直观、容易控制，也很适合现有的系统架构。

但它存在一个比较明显的特点：

每次输出主要关注的是当前应该执行什么，而不是整个系统的状态应该如何连续变化。

例如：

一次输入让角色表现出惊讶。

下一次输入让角色表现出高兴。

如果缺少额外的状态管理，系统很容易表现成两个独立动作之间的切换。

我们当然可以增加过渡动画，让惊讶逐渐减弱，再慢慢进入高兴。

不过，这种过渡主要解决的是视觉上的连续性。

我更关心另一个问题：

假设惊讶还没有完全消失，新的刺激就已经到来，那么先前的状态应该如何影响这次反应？

如果此前已经连续发生过几次类似事件，角色是否应该表现得更加敏感，或者逐渐习惯？

如果角色原本处于紧张状态，同样一次正面刺激，是否应该与平静状态下产生不同的结果？

这些问题的共同点是：

当前状态必须包含过去的影响，而新的输入又会在当前状态的基础上继续改变系统。

因此，我希望建立的不是一个不断接收指令、播放效果的模块，而是一个持续维护自身内部状态的系统。

外部输入只是改变它的因素之一。

# 2. 为什么不直接使用衰减函数？

我们可以让惊讶快速消退，让紧张持续更长时间，也可以通过其他函数构造不同的变化曲线。

对于简单的表情控制，这完全是合理的工程方案。

但问题在于，当系统内部存在更多变量时，它们之间可能不再是独立变化的。

例如：

高兴可能降低紧张，也可能与紧张同时存在。

连续的负面刺激可能改变系统对后续刺激的敏感程度。

同样的事件，在不同历史状态下可能产生完全不同的影响。

某些状态可能迅速变化，而另一些状态则需要更长时间才能恢复。

如果全部使用人工规则，我们需要不断设计变量之间的关系、相互作用和时间参数。

理论上，这些都可以实现。

只是当系统越来越复杂时，我们实际上是在手动定义一套心理状态演化规律。

这让我开始考虑另一种可能：

既然这些关系本质上可以看作一种动态规律，能否通过训练，让模型自己学习这些规律？

当然，使用神经网络并不意味着系统一定会更加自然。

甚至可能出现一种情况：一个经过精心设计的简单动力学模型，就能够达到与神经网络相近的效果。

但我认为这件事值得通过实验验证，而不是直接作出判断。

我希望通过训练来获得这个函数，而不是预先为每一种情绪定义完整的变化规则。

这样，一次刺激的影响就不必在本次计算结束后消失。

它可以通过内部状态继续影响后续的变化。

同时，相同的刺激也不必始终产生相同的结果。

因为每次输入进入系统时，面对的内部状态可能已经不同。

这里还有一个比较重要的区别：

输入的刺激，并不等于系统最终产生的情绪。

例如，外界发生了一件令人高兴的事情，我们可以把它转化为一次正面刺激。

但这不意味着角色的高兴程度必须立即变成某个数值。

如果角色此前处于悲伤、紧张或者疲惫的状态，最终形成的反应可能会有所不同。

我希望这些差异由内部状态和训练得到的动态规律共同决定，而不是每次都由 LLM 重新指定完整的情绪参数。

# 4. 情绪之外，还应该有行为倾向

继续思考之后，我发现只输出情绪可能仍然不够。

因为情绪并不直接等于行为。

同样感到高兴，不同角色可能表现出完全不同的行为方式。

有些人会主动表达，有些人则比较克制。

一个人即使感到害怕，也可能因为好奇而选择继续探索。

更复杂的是，不同的行为倾向甚至可能同时存在。

例如，一个比较害羞的角色，在受到夸奖之后，可能同时产生较强的互动意愿与回避倾向。

这两种倾向并不一定矛盾。

它们可以共同影响角色最终采取的行为。

因此，我准备让 NeuroBrain 从同一个内部状态中输出两类信息：

第一类是当前情绪状态。

第二类是当前行为倾向。

行为倾向初步包括互动、回避、表达、探索、主动性以及行为激活程度六个维度。

这里并不打算让情绪先经过某个固定公式，再转换为行为。

相反，我希望情绪与行为倾向都通过训练，从同一个内部系统中产生。

这样，系统就不仅能够描述角色当前处于怎样的心理状态，还可以为外部决策提供一定的行为动机信息。

至于具体说什么、做什么动作，仍然交给外部的语言模型与执行系统处理。

NeuroBrain 本身不需要理解完整的自然语言，也不负责直接操纵 Live2D 参数。

它只负责心理状态与行为倾向的动态演化。

# 5. 不只是 Live2D，也可以用于角色扮演

这里其实是我觉得 NeuroBrain 很有扩展价值的地方。

最开始的需求来自 Live2D，但如果这个系统真的能够学习连续的心理变化，那么它能提供的东西显然不只有表情。

例如，在 AI 角色扮演中，我们通常通过 Prompt 定义角色的性格、背景和行为方式，再通过上下文和 Memory 保持人物表现的一致性。

这种方式已经可以让角色表现得相当自然。

但我希望在此基础上，增加一个独立的心理状态来源。

假设我们正在扮演一个比较内向、敏感，但又很在意用户的角色。

经过一段时间的交流，她已经对用户建立了一定的信任。

这时用户突然说，自己最近遇到了一些不愉快的事情。

传统方式下，LLM 会根据角色设定与对话内容，生成一段符合人物性格的安慰。

但如果存在 NeuroBrain，我们就可以多做一步。

首先，当前对话会被转化为刺激，影响角色的内部状态。

随后，NeuroBrain 根据之前的状态和新刺激，输出当前的情绪与行为倾向。

例如，她可能出现：

  • 较高的关心与互动倾向。
  • 一定程度的紧张和担忧。
  • 想主动了解情况的倾向。
  • 相对克制的表达倾向。

这些状态并不直接指定她应该说哪句话。

但它们可以为 LLM 提供更加具体的角色行为依据。

在生成回复时，LLM 可以结合这些信息判断：

角色此刻是否倾向于主动询问？

是否希望继续靠近对方？

是否因为紧张而表现得有些犹豫？

是否更倾向于温和地表达关心，而不是直接给出很多建议？

最终，LLM 仍然负责生成自然语言和组织具体行为，但这些行为可以受到一个持续存在的心理系统影响。

这样做的意义，不只是让角色说话时多带一点情绪。

而是让角色在连续交互中，逐渐形成具有历史依赖的行为倾向。

例如，一个角色可能因为此前的互动，对某些话题表现得更加敏感。

也可能随着信任增长，逐渐变得愿意主动表达。

甚至在某些时候，她当前的心理倾向可能与原本的性格设定产生一定冲突。

我觉得这些变化很值得研究。

因为对于角色扮演来说，人物是否自然，并不只取决于某一句台词写得是否符合设定。

还取决于她为什么会在这个时候说出这句话，以及此前发生的事情是否真正影响了她。

NeuroBrain 可能提供的，正是这样一层介于角色设定与具体行为之间的动态信息。

它并不代替 LLM 的理解和推理，而是让 LLM 在生成角色行为时，能够参考一个持续演化的内部心理状态。

未来即使不使用 Live2D，只运行一个纯文本角色扮演系统，也可以尝试接入 NeuroBrain。

# 6. 性格能否通过训练形成？

这部分是我目前最想验证的内容之一。

在现有的大语言模型角色系统中，人格通常通过 Prompt、角色设定和记忆进行约束。

例如，我们可以要求一个角色表现得内向、敏感、好奇，或者比较沉稳。

LLM 会结合这些描述，在生成回复时表现出相应的风格。

这种方式已经非常成熟，也有实际效果。

但我想尝试的是另一种形式。

如果我们把性格看成一种相对稳定的心理反应倾向，那么能不能让这种倾向通过模型训练形成？

比如，面对相同的夸奖，一个比较外向的角色可能更容易产生表达和互动倾向。

而另一个比较内向的角色，即使同样感到高兴，也可能保留较强的紧张和回避倾向。

这种差异并不一定需要表现为固定规则。

它也可以尝试通过不同的训练数据，在模型的状态演化规律中形成。

当然，性格并不意味着某个角色永远按照同一种方式反应。

内向的人也可能主动。

敏感的人也可能表现得平静。

所以我们需要训练的，不应该是某种简单的情绪对应关系。

而是一个角色在不同环境、历史状态和刺激组合下，相对稳定的反应倾向。

能否真正学到这种规律，目前还是一个需要验证的问题。

# 7. 目前选择的技术方案

对于底层模型，我准备先采用 CfC（Closed-form Continuous-time Neural Network）。

CfC 是一种具有连续时间建模机制的递归神经网络。

它能够将时间间隔明确纳入状态更新过程，并且可以通过训练优化内部动态。

这个特点与 NeuroBrain 的需求比较契合。

因为我希望系统不仅能够保留此前的状态，还能够学习这些状态如何随时间变化。

目前暂定使用 PyTorch 实现，采用 512 维内部隐状态，并在前面设置一个 32 维输入编码层。

这里的 512 维并不对应 512 种情绪，也不代表 512 个真实生物神经元。

它们只是模型内部用于表示和演化状态的隐变量。

至于这些变量最终学习到什么，需要通过训练和实验观察。

情绪输入与输出方面，我准备采用普鲁奇克（Plutchik）提出的八种基本情绪作为初始参考：

喜悦、信任、恐惧、惊讶、悲伤、厌恶、愤怒和期待。

每种情绪使用独立的数值表示，并允许多种情绪同时存在。

虽然普鲁奇克的理论包含情绪对立与组合关系，但我暂时不准备把这些关系作为神经网络的硬性约束。

它更多是一个便于生成训练数据、观察状态的分类体系。

最终的实验结构大致如下：

八维情绪刺激 + 八维历史情绪条件 → 输入编码层 → CfC-512 → 八维情绪状态 + 六维行为倾向

其中，历史情绪条件暂时使用预设数据，为未来与长期记忆系统结合预留接口。

这些配置并不是最终确定的最优方案。

我只是希望先选定一个具有可训练性和扩展空间的结构，完成第一轮实验。

# 8. 最困难的部分可能是训练

模型结构确定之后，接下来的问题就是如何让它真正学到合理的心理变化。

目前我考虑从连续的故事、剧本以及角色互动场景入手。

例如，准备一段包含期待、失望、解释和情绪恢复的连续剧情。

然后根据角色设定，使用 LLM 辅助生成不同时间点的心理刺激，以及对应的参考情绪和行为倾向。

再将这些信息组织成时间序列，用于训练模型。

在训练过程中，NeuroBrain 根据输入与自身隐状态不断产生新的状态，并在指定的时间点输出预测结果。

随后，将预测结果与参考数据比较，通过反向传播更新模型参数。

这里最重要的并不是让模型学会某个事件对应哪种情绪。

而是让它学习：

为什么同一个刺激，在不同状态下会产生不同反应？

为什么某些影响会迅速消失，而另一些影响会持续更长时间？

为什么连续发生的事件，可能与单独发生时产生不同的结果？

以及，情绪变化如何与行为倾向形成联系？

当然，使用 LLM 生成数据也存在问题。

首先，它提供的参考情绪并不是客观真值。

其次，LLM 可能倾向于生成过于规律、缺少复杂性的情绪变化。

如果训练数据本身只包含简单的刺激与情绪对应关系，那么即使使用复杂神经网络，最终也可能只学到一套简单规则。

因此，我希望后续的训练案例能够包含不同的初始状态、连续刺激、复杂情绪以及具有不同性格特征的角色反应。

同时，需要通过未参与训练的场景检验模型，而不是只观察训练过程中的误差。

# 9. 历史状态与长期记忆

NeuroBrain 虽然需要保留历史影响，但我并不希望它承担全部记忆功能。

这里需要区分两种不同的信息。

一种是此前经历对当前心理状态造成的影响。

例如，角色刚刚经历一次不愉快的互动，虽然事情已经结束，但内部状态仍然受到影响。

这种连续性的心理变化，应该由神经网络自身的隐状态承担。

另一种则是具体发生过的事情。

例如，某次对话的内容、与某个人的约定，或者很久之前的一段经历。

这些信息更适合交给现有的 Memory 系统。

AG99 目前已经拥有近期对话摘要和长期 Story 检索机制，因此没有必要在 NeuroBrain 中重新实现一套完整的记忆系统。

未来可以考虑为 Story 增加情绪信息。

当某段历史经历被重新检索出来时，由外部系统根据当前情境生成相应的刺激或历史条件。

但这并不意味着过去的情绪可以直接覆盖当前心理状态。

某件事情发生时的感受，与今天重新回忆它所产生的影响，是两个不同的概念。

第一阶段暂时不会涉及完整的 Memory 集成。

先验证模型自身的动态能力，再考虑如何接入具体经历。

# 10. 我准备验证什么？

目前 NeuroBrain 还处在初始设计阶段。

虽然已经选定了初步的模型结构，但真正的效果仍然需要通过实验判断。

我最关心的几个问题是：

第一，模型能否学到合理的状态延续与消退？

当一个刺激结束之后，它是否能够按照训练得到的规律逐渐变化，而不是简单地维持不变或突然归零？

第二，模型能否形成真正的历史依赖？

同样的刺激，在不同初始状态、不同刺激顺序下，是否能够产生有意义的差异？

第三，模型能否同时学习情绪和行为倾向？

两组输出能否反映同一个内部状态的变化，而不是退化成彼此独立的输入输出映射？

第四，模型能否通过训练形成稳定的反应特征？

面对未见过的场景，它是否还能表现出与目标性格相符的动态规律？

第五，这些状态能否改善实际的角色扮演表现？

如果将 NeuroBrain 的状态提供给 LLM，角色在长期互动中是否能够表现出更加连贯、具有历史依据的反应？

第六，它是否真的比简单的规则系统更有价值？

如果最终发现几个衰减函数加上简单的状态管理就足以达到相同效果，那么引入更复杂的神经网络可能并没有意义。

我希望通过实际训练和对照实验，而不是凭借对某种算法的偏好来判断。

后续还准备建立一个用于观察模型的实验环境。

除了查看数值曲线，也可以让 NeuroBrain 为一个 LLM 角色提供心理状态与行为倾向，观察这些信息是否能够改善角色在连续交互中的表现。

不过目前还是以核心模型和训练能力为优先。

# 11. 结语

回过头来看，NeuroBrain 的想法其实来自一个比较具体的工程问题。

我原本只是希望改进 LLM 对 Live2D 表情和动作的驱动效果，让角色的表现不再是简单的指令切换，而能够具有自然的延续、变化与恢复。

但当我进一步考虑状态残留、历史依赖以及多个刺激之间的相互作用时，逐渐发现这些需求背后实际上指向了一个更一般的问题：

如何构建一个能够持续演化，并且能够从数据中学习自身状态变化规律的系统？

如果这样的系统能够成立，它所提供的能力就不再局限于 Live2D。

它可以为虚拟角色提供连续的情绪状态，也可以为角色扮演中的 LLM 提供行为倾向和心理反应依据，未来还可能结合长期记忆，让过去的经历参与新的心理变化。

更重要的是，我希望通过训练，让角色的性格不只是 Prompt 中的一段描述，而能够部分体现在它面对不同刺激时所表现出的反应规律中。

至于它能否真正形成我们期望的性格与心理连续性，现在还不能确定。

CfC 只是当前选择的一种实现方式，普鲁奇克八维情绪也只是初步的外部表示。

真正需要回答的问题，是这种可训练的内部动力学机制，能否在复杂情境下产生比简单规则更合理、更稳定的状态变化。

我准备先围绕这个问题完成第一轮实验。

NeuroBrain 的探索也就从这里开始。
